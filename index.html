Built for the way you actually read.

Drop in a document and start asking. DocChat finds the relevant passages and answers with citations you can verify.

Any document, any format

PDF, DOCX, TXT and Markdown. Up to 10 MB per file, processed entirely in memory.

Cited answers

Every answer links back to the passage it came from, so you can check the source in one click.

Private by default

Documents are processed in memory and never persisted. Nothing leaves your session.

Fast, sub-2s answers

TF-IDF retrieval plus an optional LLM for natural-language answers. Median latency under 2 seconds.

Works offline-friendly

Extractive answers need no API key. Add an OpenAI key only if you want LLM-generated responses.

Conversational

Ask follow-ups, drill into sections, and reset anytime. Your document, your questions.

Three steps. That's it.

No accounts, no configuration. From upload to answer in under a minute.

Upload your document

Drag and drop a PDF, DOCX, TXT or Markdown file. We extract and chunk the text in memory.

Ask a question

Type anything — a clause, a number, a summary. We retrieve the most relevant passages.

Get a cited answer

Read the answer with its source passage attached, so you can verify every claim.

Your documents stay yours.

We built DocChat so the sensitive stuff never leaves your session.

  • Processed in memory — nothing written to disk
  • No account required to try it
  • Open source, self-hostable backend
  • Optional LLM key stays in your environment

Run it yourself

DocChat is a small, self-contained Python server. Clone, install two optional deps, and run.

python3 server.py
# then open http://127.0.0.1:8000
