# Launch Plan — AI Document Chat (RAG)

A one-page launch plan for shipping v1 of AI Document Chat next month (November 2026).

## How to view

Open `index.html` in any browser. It is designed to print to a single A4 page
(File → Print → Save as PDF, or Ctrl/Cmd+P).

## Contents

- `index.html` — the one-page launch plan (styled, print-ready)
- `launch-plan.pdf` — the same plan exported as a single-page PDF (if present)
